# FAKE OR REAL — Chrome / Edge Extension

Evidence-Based Digital Trust & Safety Guard for browser navigation.

## Features
- **Instant Domain & Identity Risk Check**: Inspects the active tab's domain, SSL certificate, organization mismatch, and threat intelligence.
- **Trust Score & Confidence Display**: Provides quick 0–100 score, risk level, and forensic check status.
- **Real-Time Website Warning (Non-Manipulative UI)**: For confirmed lookalikes or high-risk domains, displays a transparent warning banner with:
  - *View Evidence* (links to deep forensic audit)
  - *Return to Safety* (redirects to search/safe page)
  - *Continue Anyway* (respects user autonomy without manipulative dark patterns)
- **Emergency Button**: One-click jump to the "I Already Clicked" emergency triage checklist.

## Installation in Chrome / Edge
1. Open Google Chrome or Microsoft Edge.
2. Navigate to `chrome://extensions` or `edge://extensions`.
3. Enable **Developer mode** (toggle in top right).
4. Click **Load unpacked**.
5. Select the `c:\p1test\extension` folder.
6. The FAKE OR REAL shield badge will now appear in your browser toolbar!
